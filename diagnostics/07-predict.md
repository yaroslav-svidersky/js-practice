## 7.1

Предсказание:
console.log(1 + "2"); // 3
console.log("5" - 2); // 3
console.log(1 == "1", 1 === "1"); // true, false
Почему:
1 + "2" и "5" - 2 автоматически приводит типы к числам (вероятно) и дальше вычисляет. 1 == "1" приводит типы к числам и сравнивает (или к строкам, в любом случает тут истина). 1 === "1" false, тут сравниваются число и строка, а тройное равно не приводит тип к одному.
На самом деле:
1 + "2" привел 1 к строке, произошла конкатенация "1" + "2" = "12"
В остальных случаях результат совпадает с предсказанием.

## 7.4

Предсказание:
function counter() {
let count = 0;
return function () {
count++;
return count;
};
}
const c = counter();
c();
c();
console.log(c()); // 1
Почему:
Вернет один, потому что каждый раз при вызове функции counter() создается новая внутренняя переменная let count = 0. Далее функция counter() возвращает некую безымянныую функцию, которая инкрементирует +1 let count и возвращает count. Несколько вызовов counter() создают несколько отдельных вызовов. В принципе эта функция может возвращать только 1.
На самом деле:
Я упустил строчку с const c = counter(); Так то вроде понятно, мы вызываем три раза одну и ту же функцию, а её внутренняя переменная сохраняется между вызовами. console.log(c()); даёт 3.
