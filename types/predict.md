// 1. typeof
typeof null // null, потому что у нала свой особый тип.
На самом деле: object. Оказывается это не совсем свой тип.
typeof [] // object, потому что массив это один из видов объектов.
На самом деле: object, ответ верный.
typeof function () {} // function, хотя функция тоже объект, но кажется typeof для функций пишет function.
На самом деле: function, ответ верный.

// 2. Явное приведение к числу
Number("42") // 42, потому что это просто число строкой.
На самом деле: 42, ответ верный.
Number("") // NaN вероятно, ведь это пустая строка.
На самом деле: 0. Оказывается, пустая строка это 0. "Ничего" можно всё таки посчитать.
Number("42abc") // NaN вероятно, потому что тут есть буквы - их нельзя привести к числам.
На самом деле: NaN, ответ верный.
Number(true) // 1, ведь 0 - false, а 1 - true.
На самом деле: 1, ответ верный.
Number(null) // NaN вероятно. Вторая догадка null.
На самом деле: 0. null это ноль, ну конечно... Моя вторая догадка особенно идиотская, ведь мы же специально приводим к числам через Number().
Number(undefined) // NaN вероятно. Вторая догадка undefined.
На самом деле: NaN, ответ верный. Вторая догадка идиотская, как и в Number(null) выше.

// 3. Неявное приведение
String(123) + 1 // строка '1231', потому что 123 приводится к строке, а плюс со строками и числами всегда конкатенация.
На самом деле: строка 1231, ответ верный.
"3" * "4" // 12 вероятно. -, *, / со строкой и числом приводят строку к числу. Тут только строки, но состоящие из чисел, поэтому вероятно обе приведутся к числам и перемножаться.
На самом деле: 12, ответ верный.
true + 1 // 2 вероятно. true приведется к числу 1. Вторая догадка, что в обратную сторону true + true = false.
На самом деле: 2, ответ верный.
[] + [] // [] вероятно. Строки это массивы, их можно склеивать и получать новые строки. Может быть получится пустой массив с lenght 2, я хз.
На самом деле: вообще ошибка, а console.log([] + []) ничего не даёт. Может надо иначе проверять.

// 4. Приведение к boolean
Boolean("") // false вероятно, ведь это пустая строка. Была бы не пустой, было бы true.
На самом деле: false, ответ верный.
Boolean("0") // true веротяно, ведь это не пустая строка.
На самом деле: true, ответ верный.
Boolean(0) // false, ведь это ноль, а 1 - true.
На самом деле: false, ответ верный.
Boolean([]) // false вероятно, ведь это пустой массив.
На самом деле: true. Пустой массив это истинное значение, понятно...
Boolean({}) // false вероятно, такая же логика, как и с массивом - пустой, значит ложное.
На самом деле: true. Истинный пустой объект.
